# 開闢 2.2.1

- 公式データベースに追加された新しいカード107枚の照合データを追加しました。別イラストが加わった4枚は、新旧どちらのイラストも判定できます。
- カードデータの更新に失敗したとき、公式サイトの作りが変わった可能性と、最新版の確認を案内するようになりました。ダイアログの［ダウンロードページを開く］から、ダウンロードページをブラウザーで開けます。
- カード名の一覧を一部しか読み取れなかったとき、取得済みのカード名を置き換えないようにしました。
- 画像を1枚も取得できなかったときに「新しいカードセットはありませんでした」と表示していたのを、取得できなかった件数の表示に直しました。

新しいカードの名前を表示するには、［カードデータ更新］→［カード名を取得］を実行してください。

## インストール・更新

`mdript-v2.2.1-windows-x64.zip` を展開し、`mdript.exe` を起動してください。Windows用です。WebView2 Runtimeが必要です。

アプリを終了してから実行ファイルを入れ替えてください。設定・カード名・登録済みデータは `%APPDATA%\mdript-v2` に残ります。同梱の `SHA256SUMS.txt` で配布ファイルのハッシュを照合できます。
