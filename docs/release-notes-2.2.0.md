# 開闢 2.2.0

- デッキ編集などで開くカード詳細画面（左にカードが出る画面）のスクリーンショットからも、カードを切り抜いて保存できるようになりました。日本語版・英語版、モンスター・魔法・罠、リンク・ペンデュラムなどの詳細画面で確認しています。
- 詳細画面のカードは拡大画面の2/3の大きさなので、既定では `detail/` に分けて保存します。設定の「詳細画面」で「名前に `_detail` を付ける」を選ぶと、拡大画面と同じフォルダに `_detail` を付けて保存します。どちらでも、同じカードの拡大画面の画像とは別に保存されます。
- 拡大画面の判定と保存は変わりません。拡大画面の背景に残る詳細画面のカードを、詳細画面として保存することはありません。

これまで詳細画面の画像は「カードなし」か、別のカード名の「要確認」として `review/` に保存されていました。詳細画面を処理したことがある場合は、`review/` の中を確認してください。

## インストール・更新

`mdript-v2.2.0-windows-x64.zip` を展開し、`mdript.exe` を起動してください。Windows用です。WebView2 Runtimeが必要です。

アプリを終了してから実行ファイルを入れ替えてください。設定・カード名・登録済みデータは `%APPDATA%\mdript-v2` に残ります。同梱の `SHA256SUMS.txt` で配布ファイルのハッシュを照合できます。
